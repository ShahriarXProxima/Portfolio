# 💻 Tech Stack & AI Integration

This document outlines the technologies, design inspirations, and AI prompts utilized during the creation of this modern portfolio website.

## 🛠️ Tech Stack

The portfolio is built on a modern, high-performance frontend stack:
- **Framework**: [React 18](https://reactjs.org/)
- **Language**: [TypeScript](https://www.typescriptlang.org/) for robust type safety.
- **Styling**: [TailwindCSS v4](https://tailwindcss.com/) for rapid, utility-first styling, paired with custom CSS for complex animations.
- **Build Tool**: [Vite](https://vitejs.dev/) for extremely fast Hot Module Replacement (HMR) and optimized builds.
- **Icons**: [Lucide React](https://lucide.dev/) for clean, customizable SVG iconography.

## 🎨 Design Inspiration & References

To achieve a modern, premium aesthetic, inspiration was gathered from leading design platforms:
- **Behance**: For case study layouts, typography scales, and high-end agency portfolio structures.
- **Pinterest**: For discovering trendy micro-interactions, dark/light mode color palettes, and glassmorphism UI examples.
- **Dribbble**: For UI component inspiration (buttons, cards, timelines) and organic, non-boxy "bento" alternatives.
