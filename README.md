# 🚀 Shahriar's Portfolio

Welcome to my personal portfolio repository! This project serves as a showcase of my work, skills, articles, and design experiments, built with modern web technologies and a focus on sleek, interactive user experiences.

## ✨ Features

- **Modern UI/UX**: Implements cutting-edge design trends including glassmorphism, dynamic scroll animations, and organic layouts.
- **Responsive Design**: Fully optimized for mobile, tablet, and desktop viewing.
- **Dynamic Theming**: Built-in support for Light and Dark modes with a custom, high-performance interactive shimmer background.
- **Interactive Case Studies**: Detailed project displays with alternating layouts and engaging hover states.
- **Scroll-driven Animations**: Utilizing advanced canvas drawing and CSS masks for performant background effects.

## 🛠️ Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/ShahriarXProxima/Portfolio.git
   cd Portfolio/Project
   ```

2. **Install dependencies:**
   Make sure you have Node.js installed, then run:
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```
   Open your browser and navigate to the localhost URL provided in your terminal.

4. **Build for production:**
   ```bash
   npm run build
   ```

## 📂 Project Structure

- `/src/components` - Reusable UI components (Hero, About, Projects, Articles, etc.)
- `/src/data` - Static data for articles and content.
- `/src/resources` - Images, icons, and static assets.
- `/src/index.css` - Global styles, Tailwind directives, and custom CSS variables.
- `/src/App.tsx` - Main application entry point handling routing and layout structure.
